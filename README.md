# StickerForge CS2

Start de website zo:

```bash
npm install
npm run dev
```

Start ook de bestaande backend in een tweede terminal:

```bash
cd backend
npm install
npm run dev
```

Laat het terminalvenster open staan. Open daarna:

```text
http://localhost:5173/
```

De craft editor staat op:

```text
http://localhost:5173/craft
```
